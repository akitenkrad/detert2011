# CLI リファレンス

[English](cli.md) | [日本語](cli.ja.md)

`detert` バイナリは 4 つのサブコマンドを持つ．1 回の実行が [runvault](https://github.com/akitenkrad/rs-runvault) の run 1 本になる．`--output-dir`（既定 `results`）配下の run ディレクトリの作成と命名は runvault が持ち，`run.json` / `config.json` / `metrics.csv` / `status.json` / `manifest.csv` も runvault が書く．自前のタイムスタンプ付きディレクトリも `results/latest` シンボリックリンクも作らない．

`metrics.csv` の形は `run_uid,step,step_unit,scope,name,value` で固定されている（long 形式）．旧来のステップ別の列はそれぞれ `scope=run`・`step_unit=step` の指標名になり，run 全体を 1 つの値で表すもの（`final_round`・`converged`・`silence_voice_corr_timeavg` など）は `step` を持たない．対象の run は `runvault path --experiment detert --latest` で解決する．`results/` を自分で glob しない．

単一構成の実行．

| フラグ | 既定値 | 意味 |
|--------|--------|------|
| `--llm-mode` | `rule` | `llm` / `rule` / `rule_no_ivt`（排他）． |
| `--n` | — | 総従業員数（`n_teams × team_size` を上書き）． |
| `--n-teams` | `8` | チーム数． |
| `--team-size` | `25` | チームあたり従業員数． |
| `--n-levels` | `3` | 階層レベル数． |
| `--network-model` | `watts-strogatz` | `watts-strogatz` / `erdos-renyi` / `barabasi-albert`． |
| `--network-k` | `6` | Watts–Strogatz k． |
| `--network-beta` | `0.1` | Watts–Strogatz β / Erdős–Rényi p． |
| `--ivt-mean` | `0.55` | IVT 平均強度 ι̅． |
| `--ivt-sd` | `0.20` | IVT 強度の標準偏差． |
| `--beta-psafety` | `1.2` | β_ψ（VOICE ロジット）． |
| `--beta-fear` | `1.5` | β_f． |
| `--beta-ivt` | `2.0` | β_ι（IVT 主効果；較正済み HiCo 点）． |
| `--p-retaliate` | `0.05` | エージェント・ステップ別報復確率． |
| `--shock-t` | `24` | 外生 σ ショックのステップ． |
| `--t-max` | `60` | 最大ステップ． |
| `--runs` | `1` | 独立試行数（出力は最終試行を反映）． |
| `--seed` | `42` | コア層 seed． |
| `--llm-temperature` | `0.0` | LLM 温度． |
| `--llm-seed` | `0` | LLM seed オフセット． |
| `--cache-path` | `.llm_cache/cache.json` | プロンプト→応答キャッシュ（LLM モード）． |

出力：`config.json`（条件は `parameters` の下），`metrics.csv`（ステップ別指標 + run スコープ指標），`artifacts/agents.csv`（最終ステップの従業員 1 人 1 行．カテゴリの列を持つ表なので表のまま置く），`llm` モードでは `run.json` の `llm` ブロック（provider / model / temperature）．

`--runs N` のとき記録されるのは最後の試行の指標で，これは移行前と同じ．`runs` は `parameters` にある．

## `sweep`

`β_ι × ψ̄ × seeds` の直積．

| フラグ | 既定値 | 意味 |
|--------|--------|------|
| `--llm-mode` | `rule` | 意思決定モード． |
| `--beta-ivt-min/max/step` | `0.0 / 1.6 / 0.2` | β_ι グリッド． |
| `--psafety-mean-values` | `0.3,0.5,0.7` | ψ̄ 軸の値． |
| `--runs` | `5` | セルあたり試行数． |
| `--t-max` | `60` | 最大ステップ． |
| `--seed` | `42` | ベース seed． |

出力：格子の定義を持つ親 run（`subcommand=sweep`）と，セル × 試行ごとの子 run（`subcommand=run`）．親は `master_seed` を持たない — 単一のシードではなくシードの列で駆動されるためである．子は実際に使われた派生シードを `master_seed` に持ち，同一セルの繰り返しは `replicate_index` で分ける．ψ̄ は `Config` のフィールドではないので，子が `parameters.psafety_mean` として持つ．

`sweep_summary.csv` は無い．同じ表は `detert_tools.run_io.sweep_table` が子から組み直す．

## `ablation`

seed 範囲にわたり意思決定モードを対比する．

| フラグ | 既定値 | 意味 |
|--------|--------|------|
| `--modes` | `rule,rule_no_ivt` | カンマ区切りのモード． |
| `--seed-start` / `--seed-end` | `0` / `30` | 包含的 seed 範囲． |
| `--t-max` | `60` | 最大ステップ． |

出力：全モードを含む **1 本の** run．IVT 主効果は 1 回の実行の中で 2 つの腕を測った差なので，腕を子 run に割ると主張がどの run にも属さなくなる．

試行 1 本は `events.jsonl` の `x.detert2011.trial` 行（モード・シードと 3 つの観測量）．これらに時間軸は無く，`metrics.csv` に並べると全行が同じ主キーを名乗るため指標にはしない．`metrics.csv` が持つのはモード別の平均（`<mode>_mean_upward_silence_rate`・`<mode>_n_trials`）と比較そのもの（`ivt_effect_delta`・`ivt_effect_cohens_d`）．

## `reproduce`

設計アンカー（HiCo ≈ .50，silence–voice r ≈ −.55，弁別的同時発火 < .50）に対するモード別定常レポート．Table 4 風レポートと ABM ルール発火行列から再現する CFA 系適合度指標の **両方** を得るには Python ツール `detert-tools reproduce` を使う．

出力：3 つの観測平均と `checks_passed` / `checks_total` が run スコープの指標，アンカーごとの帯と判定は `x.detert2011.check` イベント（判定はカテゴリであって数ではない）．この帯は本再現実装が置いたアンカーであって論文の報告値ではないので，`reference.csv` には **書かない**．
